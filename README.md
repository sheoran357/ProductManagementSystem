# Product Management System

A simple product management application built with ASP.NET Core 10.

The solution contains two separate applications:

- **ProductManagement.API** – REST API, business rules and database access.
- **ProductManagement.MVC** – Razor pages that call the API through HttpClient.

## Technology

- C# and ASP.NET Core 10
- Entity Framework Core 10
- SQLite
- ASP.NET Core MVC
- HttpClient
- OpenAPI / Swagger

## Project status

The application is being built in small, testable milestones. Setup and run instructions will be added as the implementation is completed.
